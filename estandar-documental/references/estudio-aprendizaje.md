# Perfil ESTUDIO_APRENDIZAJE

## Objetivo

Optimizar la secuencia **comprender → conectar → recordar → recuperar → aplicar**. Debe ser más visual y usar color con mayor intención que los demás perfiles, sin convertirse en una infografía decorativa ni sacrificar profundidad.

## Recursos recomendados

Usar solo cuando aporten:
- mapas conceptuales / marcos para relaciones;
- ejemplos resueltos: explicación → aplicación/cálculo → interpretación;
- comparativas para conceptos confundibles;
- idea clave para recuperación rápida;
- error frecuente / atención cuando exista un error probable;
- preguntas breves de recuperación para recordar sin releer;
- preguntas de aplicación para transferir el concepto;
- síntesis de capítulo cuando una unidad lo justifique;
- tablas y diagramas para síntesis o relaciones reales.

## Color semántico

El color debe tener **rol estable**, no variar por decoración. La paleta concreta depende del proyecto, pero los roles deben ser distinguibles y accesibles.

Roles sugeridos:
- concepto/principio → primario;
- aplicación/ejemplo → secundario;
- atención/error → advertencia;
- marco/conexión → acento diferenciador;
- evidencia/fuente/contexto → neutral.

Nunca transmitir significado solo por color: acompañar con etiqueta, icono, título, forma o estructura. Verificar contraste.

## Composición

- Segmentación antes que compresión.
- Una unidad visual puede ocupar espacio sustantivo si mejora aprendizaje.
- No imponer una idea por página; sí una ruta visual clara.
- Evitar tarjetas repetitivas si solo contienen párrafos.
- Las imágenes decorativas o genéricas tienen prioridad mínima.

## Uso de especialistas

Canva/diseño es útil para diagramas, marcos, mapas conceptuales, tarjetas de aprendizaje o síntesis visuales. Word/DOCX sigue siendo el contenedor canónico cuando la salida debe ser editable, navegable y accesible. No rasterizar texto principal innecesariamente.
