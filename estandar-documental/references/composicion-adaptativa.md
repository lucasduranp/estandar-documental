# Composición Adaptativa

## Regla central

No decidir primero la forma. Identificar qué debe **entender, decidir, recordar o hacer** el lector y después elegir la representación.

| Necesidad | Primera representación a evaluar |
|---|---|
| explicar / argumentar | texto estructurado |
| comunicar una conclusión | titular + evidencia |
| consultar valores exactos | tabla |
| comparar magnitudes | barras / puntos / tabla si importan valores exactos |
| mostrar tendencia | serie temporal |
| mostrar composición | barras apiladas / tabla según precisión requerida |
| mostrar proceso | flujo |
| mostrar causalidad o lógica | diagrama causal / árbol |
| mostrar relaciones o arquitectura | mapa / matriz / árbol |
| demostrar evidencia real | foto, captura o documento fuente |
| ejecutar una tarea | checklist / pasos / matriz operacional |
| nada mejora el texto | texto, sin visual artificial |

## Control de Utilidad Visual

Todo visual debe responder: **¿qué entiende el lector mejor, más rápido o con menor esfuerzo gracias a este recurso?**

Funciones válidas: explicar, comparar, evidenciar, revelar patrón, relacionar, orientar, priorizar o facilitar recuperación.

Reconsiderar o bloquear cuando el recurso solo decora, rellena espacio, repite el texto o convierte párrafos en cajas/flechas sin reducir complejidad.

## Densidad y espacio

La página optimiza comprensión, no porcentaje de ocupación. Alta densidad puede ser correcta si la jerarquía reduce esfuerzo; mucho espacio blanco puede ser correcto si separa significado.

Ante falta de espacio:
1. eliminar redundancia;
2. sintetizar;
3. mejorar arquitectura;
4. cambiar representación;
5. redistribuir composición;
6. añadir página;
7. ajustar tamaños dentro de rangos profesionales.

Nunca empezar por reducir todo hasta que quepa.

## Redundancia

- **Complementarios**: cumplen funciones distintas → conservar.
- **Sustitutivos**: comunican esencialmente lo mismo → elegir el mejor.
- **Redundantes**: uno no aporta nada material → eliminar.

## Aplicabilidad

El documento debe permitir cumplir su propósito: decisión localizable, pasos ejecutables, hallazgos/evidencia distinguibles, reglas recuperables o aprendizaje aplicable. No todos los documentos necesitan una recomendación, pero todos necesitan un uso claro.

## Regla de cierre

Cuando propósito, integridad, legibilidad, composición, fidelidad, aplicabilidad y controles técnicos pasan, detener el refinamiento estético. No sobrediseñar por preferencia.
