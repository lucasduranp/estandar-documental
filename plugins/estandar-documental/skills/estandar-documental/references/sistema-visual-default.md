# Sistema Visual por Defecto — Editorial Ejecutivo

## Cuándo usarlo

Aplicar este sistema **solo en CREAR** cuando no exista una referencia visual aprobada, una marca definida o una instrucción visual específica del usuario.

Su función es evitar resultados genéricos de Word. No es una plantilla fija: define tokens, jerarquía y criterios de composición que pueden adaptarse al contenido.

## Principio

El documento debe verse **intencionalmente diseñado** incluso en vista miniatura. Si parece un memo de Word sin sistema visual —título negro, texto negro, viñetas estándar y espaciado por defecto— el resultado no cumple el estándar profesional salvo solicitud explícita de estilo plano.

## Tipografía

Prioridad:
1. tipografía aprobada por el proyecto o referencia;
2. Avenir Next si está disponible;
3. Manrope si está disponible;
4. Aptos como fallback técnico moderno.

No usar Calibri como salida por defecto en CREAR. Verificar que la fuente elegida esté disponible o renderice correctamente; si no, usar el siguiente fallback.

Escala orientativa para A4:
- kicker / etiqueta: 8–9 pt, mayúsculas o versalitas;
- título: 22–28 pt;
- objetivo / bajada: 10–11.5 pt;
- encabezado de sección: 11–13 pt;
- cuerpo: 9.5–11 pt;
- pie / fuente / metadato: 8–9 pt.

La escala puede variar si mejora legibilidad; no reducir cuerpo por debajo de 9.5 pt para ganar espacio salvo caso excepcional justificado.

## Paleta editorial neutra

Usar roles, no colores arbitrarios:

- **Tinta principal:** #1A281F
- **Acento principal:** #5A7A2E
- **Acento secundario:** #A6C23A, solo para énfasis puntual
- **Superficie suave:** #F6F3EC
- **Texto secundario:** #59615B
- **Divisor neutro:** #D8DDD8

No es identidad de marca. Si el contexto requiere otro tono, puede cambiarse la paleta preservando los mismos roles y contraste.

## Ritmo visual

Usar un ritmo consistente de espacios: pequeño / medio / grande. Evitar espaciados arbitrarios entre bloques.

Una página compacta profesional suele contener:
- kicker o etiqueta contextual;
- título fuerte;
- objetivo/bajada;
- cuerpo principal en 2–4 bloques;
- elemento de síntesis o cierre;
- suficiente respiración para separar jerarquías.

## Recursos permitidos

- reglas finas de acento;
- superficies suaves para agrupar;
- checklist;
- línea de tiempo simple;
- agenda / banda resumen;
- matriz corta;
- callout;
- iconografía mínima solo si aporta orientación.

No decorar por llenar espacio.

## Columnas y tablas de layout

No prohibirlas de forma absoluta.

Puede usarse una tabla sin bordes o estructura equivalente para **composición simple y estable** cuando:
- mejora claramente el escaneo;
- cada columna contiene contenido breve;
- el orden de lectura es obvio;
- no se usa para párrafos largos;
- no crea semántica de datos falsa;
- el render final es correcto.

Para contenido narrativo denso, preferir flujo vertical o dos columnas como máximo.

## Arquetipos para COMPACTO_OPERACIONAL

Elegir uno según el contenido:

### A. Objetivo + bloques + cierre
Kicker → título → objetivo → 3 bloques operativos → comprobación final.

### B. Decisión + checklist
Mensaje principal → decisión/criterio → checklist operativo → riesgos/pendientes → cierre.

### C. Proceso breve
Objetivo → 3 fases → pasos cortos por fase → banda de síntesis/agenda.

No convertir estos arquetipos en plantillas rígidas. Su función es ofrecer una **dirección visual positiva**, no obligar a una composición idéntica.

## Gate de genericidad

Bloquear una salida en CREAR si, sin una instrucción explícita de estilo plano:
- usa apariencia de Word por defecto;
- todo está en negro sin jerarquía cromática;
- la tipografía es Calibri por defecto;
- solo hay título + headings + viñetas sin composición editorial;
- no existe una jerarquía visual claramente intencionada;
- el documento podría confundirse con un borrador sin diseño.

La solución no es añadir decoración, sino aplicar un sistema visual coherente.
