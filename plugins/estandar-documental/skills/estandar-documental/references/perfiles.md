# Selección de perfiles — v1.3

Los perfiles definen **qué optimizar**, no cómo debe verse cada página. La Composición Adaptativa decide representación y composición.

| Perfil canónico | Optimiza | Prueba de uso final |
|---|---|---|
| **COMPACTO_OPERACIONAL** | rapidez + acción | ¿El lector encuentra decisión, estado y próximos pasos sin releer? |
| **ANALÍTICO_NEGOCIO** | evidencia + comparación + decisión | ¿Puede evaluar conclusión, supuestos, cálculos y compensaciones? |
| **VISUAL_COMERCIAL** | narrativa + marca + comunicación respaldada | ¿Entiende la oferta/mensaje sin decoración ni afirmaciones injustificadas? |
| **REFERENCIA_RÁPIDA_OPERACIONAL** | recuperación + ejecución inmediata | ¿Puede localizar una regla, paso o dato en segundos? |
| **ESTUDIO_APRENDIZAJE** | comprender + conectar + recordar + recuperar + aplicar | ¿El diseño ayuda realmente a aprender y recuperar? |

## Principios comunes

- Un perfil puede mezclar páginas textuales, tablas y visuales si la función lo exige.
- Una restricción de una página solo existe cuando el encargo la requiere.
- Nunca miniaturizar para alcanzar un page count.
- A4 vertical es el valor por defecto, no una obligación estética universal.
- El perfil no autoriza afirmaciones sin respaldo, decoración gratuita ni pérdida de editabilidad/accesibilidad.
- La herramienta especialista elegida puede variar por perfil; Estándar Documental conserva la autoridad de diseño y aceptación.

## ESTUDIO_APRENDIZAJE

Aplicar [Estudio y Aprendizaje](estudio-aprendizaje.md). Debe usar más señalización visual que los otros perfiles, pero sin cuota fija de imágenes. Color, diagramas, ejemplos resueltos, comparativas y preguntas de recuperación se justifican por su función cognitiva.

## Especialistas

- COMPACTO_OPERACIONAL y ANALÍTICO_NEGOCIO suelen resolverse principalmente con la capacidad documental y, cuando corresponda, datos/investigación.
- VISUAL_COMERCIAL puede requerir Canva/diseño para recursos específicos.
- REFERENCIA_RÁPIDA_OPERACIONAL prioriza navegación, síntesis y consulta.
- ESTUDIO_APRENDIZAJE puede combinar DOCX + Canva/diseño para diagramas, mapas conceptuales y síntesis.

No forzar ningún perfil a una plantilla o constructor específico.
