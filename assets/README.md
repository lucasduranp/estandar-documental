# Activos

La versión activa de Estándar Documental v1.3 **no requiere un template DOCX universal ni activos visuales obligatorios**.

Razón:
- los perfiles son funciones objetivo, no plantillas;
- ADAPTAR/REPLICAR deben preservar la referencia real del proyecto;
- CREAR puede usar la capacidad documental y visual especialista disponible;
- los activos decorativos genéricos no deben imponerse.

Los recursos históricos del antiguo Core/PDS pertenecen a la regresión y no gobiernan documentos nuevos.

Si una futura versión incorpora un activo canónico, debe:
1. resolver una necesidad estable;
2. tener licencia/propiedad clara;
3. estar versionado;
4. contar con evals/regresión;
5. no reducir la flexibilidad de Composición Adaptativa.
