# Referencias de diseño incorporadas en v1.3

Estas reglas se incorporan como principios estables; no requieren búsqueda web en cada ejecución normal.

## Fuentes normativas y profesionales

- **ISO 24896:2026 — Notation for business reporting**: propósito/mensaje clave, elección entre texto/visual/combinación y notación consistente.
- **IBCS 2.0 / SUCCESS**: SAY, UNIFY, CONDENSE, CHECK, EXPRESS, SIMPLIFY, STRUCTURE; separar notación de composición.
- **Microsoft Word — accesibilidad**: encabezados reales, tablas simples/semánticas, texto alternativo, contraste y no depender solo del color.
- **ISO 24495-1 — lenguaje claro**: encontrar, comprender y usar información con facilidad.

## Aprendizaje y diseño

- **Mayer / aprendizaje multimedia**: coherencia, señalización y segmentación; un visual ayuda cuando reduce procesamiento extrínseco y apoya comprensión.
- **Duarte / documentos visuales**: jerarquía, espacio blanco y combinación de prosa/visuales para documentos que deben leerse y escanearse.
- **Column Five / diseño de informes**: conclusión principal primero, jerarquía intuitiva, visualización correcta y eliminación de recursos sin función narrativa/informativa.

## Comunidades

Usar comunidades como señal práctica para detectar anti-patrones —falta de foco, demasiados elementos compitiendo, baja jerarquía, decoración que domina el contenido—, nunca como autoridad normativa ni como regla estética rígida.

## Cuándo volver a investigar

Reinvestigar cuando: se actualiza la skill; aparece un problema no cubierto; el formato es extraordinario; una norma relevante cambia; o el usuario pide contraste explícito.
